# Чек-лист ревью требований по умолчанию

Если в документе есть свой чек-лист ревью, агент оценивает пункты из документа. Если нет — пункты ниже.

1. Техническое требование зафиксировано и покрывает бизнес-требование.
2. Функциональная спецификация имеет структурированное описание по шаблону.
3. Описаны взаимодействия систем и компонентов (sequence-диаграммы).
4. Требование покрывает спецификацию UX/UI.
5. Предусмотрена схема отката или скрытия функционала.
6. Требование может быть протестировано.
7. Описаны модель данных или поток данных.
8. Нет противоречий и явных операционных рисков.
9. Описана архитектура, есть согласование с архитекторами.
10. Изменения, влияющие на другие системы, согласованы с ответственными.
11. Нет рисков информационной безопасности.
12. Есть схема полного бизнес-процесса и реализуемой части.
13. Интеграционное взаимодействие описано чётко.
14. Документ версионирован.
